Значимые изменения проекта. Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [Unreleased]

### Добавлено
- Деплой на VPS (Ubuntu + Caddy + systemd), `zakaz.glorden.ru` (см. DEPLOY.md)
- HTTP Basic Auth (Caddy) на весь сайт, включая API
- Страница «Прайс»: редактируемый прайс-лист, поиск, лог изменений
- Единая навигация между страницами (`nav.js`), `STYLEGUIDE.md`, мобильная адаптация
- Отмена заказа (`POST /orders/{id}/cancel`)
- VK-уведомления о предложенном заказе, с тегом водителя и ссылкой на сайт
- Предупреждение в форме создания заказа, если маршрут набран латиницей
- Первые автотесты: `tests/test_queue_logic.py` — арифметика очереди (принятие/отказ/отмена)
- Журнал действий (`GET /activity`, страница «Журнал действий») — отдельная от истории заказов хронология событий: создание, предложение, принятие, отказ, завершение, отмена заказа и изменения очереди
- Самоназначение на заказ вне очереди (`POST /orders/{id}/self-assign`) — кнопка «Самоназначиться» на дэшборде, обязательная причина, сохраняется в истории заказа и журнале действий, водитель уходит в конец очереди как при обычном принятии
- Скрипт `scripts/reorder_queue.py` — ручная перестановка порядка в очереди (для редких случаев), по образцу `scripts/add_user.py`
- Страница «Статистика» (`GET /statistics/summary`) — общие счётчики по заказам (всего/завершено/активно/отменено) и разбивка по водителям (получено/завершено/отменено)

### Изменено
- Текст сообщения о самоназначении (VK-уведомление и журнал действий) переформулирован без личного глагола прошедшего времени («самоназначился») — согласование по мужскому роду было некорректным для водителей-женщин
- Текст VK-уведомления о предложенном заказе: добавлена доп. инфа из комментария, переформулировано на несколько строк
- VK-уведомление при отказе теперь называет, кто отказался, перед тем как предложить заказ следующему в очереди
- Добавлено отдельное VK-уведомление о том, что заказ принят конкретным водителем

### Исправлено
- Вёрстка кнопок «Принять»/«Отклонить»/«Завершить» на дэшборде
- `/cancel` возвращал водителя первым в очереди вместо второго
- XSS на странице истории заказов (небезопасный `innerHTML`)
- Мёртвый статус `unassigned` убран из модели и документации
- Убрано отображение сырой позиции `(позиция N)` в очереди на дэшборде
- `POST /orders`, `PUT /price/{id}` и `POST /price` возвращали пустой объект `{}` вместо созданной/изменённой записи (коммит записи в лог инвалидировал уже загруженный объект без повторного `refresh`)

### Планируется
- Решение по identity-проверкам в `/respond` и `/complete` (см. ARCHITECTURE.md)
- Курс на будущее: разделение `routers`/`services` при росте `main.py` (см. ARCHITECTURE.md)
