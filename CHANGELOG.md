\# Changelog



Все значимые изменения проекта фиксируются в этом файле.

Формат основан на \[Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).



\## \[Unreleased]

\### Добавлено

\- Деплой на VPS: Ubuntu Server + Caddy (автоматический HTTPS) + systemd, `zakaz.glorden.ru`

\- `DEPLOY.md` — инструкция по установке и обновлению на сервере

\- HTTP Basic Auth (Caddy) на весь сайт, включая API

\- Страница «Прайс» (`static/price.html`): редактируемый прайс-лист
  (`GET/POST/PUT/DELETE /price`), поиск на клиенте, лог изменений
  (`GET /price/log`)

\- Единая навигация между страницами (`static/js/nav.js`), `STYLEGUIDE.md`

\- Мобильная адаптация интерфейса (viewport, touch-таргеты, карточки
  вместо таблиц на узких экранах)

\- Отмена заказа (`POST /orders/{id}/cancel`): доступна и для ожидающих,
  и для принятых заказов; принятый водитель при отмене возвращается
  в начало очереди

\- Уведомление в общую беседу VK о новом/переданном предложении заказа
  (`app/notifications.py`, опционально через `VK_GROUP_TOKEN`/`VK_PEER_ID`),
  включает ссылку на сайт и тег водителя по `User.vk_id`, если он известен

\### Исправлено

\- Выравнивание кнопок «Принять»/«Отклонить»/«Завершить» на дэшборде —
  текст и кнопки лежали в одной строке и криво переносились

\### Планируется

\- Решение по identity-проверкам в /respond и /complete (см. ARCHITECTURE.md)



\## \[0.1.0] - 2026-07-12

\### Добавлено

\- Каркас проекта на FastAPI, структура папок `app/`, `deploy/`

\- Модели БД (`User`, `QueuePosition`, `Order`, `OrderOffer`) и Alembic-миграции

\- `GET /queue` — просмотр очереди водителей

\- `POST /orders` — создание заказа

\- `POST /orders/{id}/respond` — принятие/отказ от заказа

\- `POST /orders/{id}/complete` — завершение заказа

\- `GET /orders` — история заказов с фильтрами (`status`, `user\_id`, `limit`)

\- `GET /orders/pending` — активные предложения по заказам

\- Веб-интерфейс: дэшборд (очередь, создание заказа, принять/отклонить/завершить)

\- Веб-интерфейс: страница истории заказов с фильтрами

\- Полная русификация пользовательского интерфейса

\- Обновлённый `README.md` для первого релиза
